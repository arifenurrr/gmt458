# GMT458 – Personal Web Mapping 

## Project Overview

This project is a personal web mapping portfolio developed for the GMT458 Web GIS course. The website includes an introduction about me, software tools I have learned throughout my education, and interactive maps presenting places that are meaningful to me.

The website can be accessed through the following link:

[https://arifenurrr.github.io/gmt458/](https://arifenurrr.github.io/gmt458/)

## Website Pages

**Home:** The homepage introduces the website and provides navigation to its main sections.

**About Me:** This page contains my personal introduction and the software tools I have learned throughout my education.

**My World:** This page presents an interactive world map showing places I have visited and places I would like to visit.

**My Places:** This page displays selected places on a map and provides information about these locations.

## Technologies Used

HTML5 was used to structure the web pages, while CSS3 was used to design their layout, colors, transitions, and animations. JavaScript was used to create interactive maps, manage locations, and control map behavior. One of the maps was developed using the Leaflet library, while the other was developed using OpenLayers. OpenStreetMap provides the underlying map data. Git and GitHub were used to manage project files, record changes, and track the development process. The website was published online using GitHub Pages.

## What I Learned

Through this project, I gained practical experience in creating web pages with HTML, styling pages with CSS, and developing interactive maps with JavaScript. I learned how to create maps using Leaflet and OpenLayers, add markers, and adjust map behavior based on zoom levels. I also gained experience combining different web technologies in a single project and publishing a website through GitHub Pages.

## Use of Artificial Intelligence

I worked on this project for four days, excluding the preparation period. During this time, I received approximately three to four hours of assistance from AI, particularly with technical topics I found challenging.

I mainly used AI to understand JavaScript code, adjust map zoom behavior, prevent the world map from repeating horizontally, and ensure that location markers appear only at specific zoom levels.

I evaluated and applied AI-generated suggestions according to my project's needs and checked the changes I made.
